# Guanosine + hemin

Designing a Four-Helix Nucleopeptide Bundle Capable of Hemin Binding

Christie Stevkovski, Alexander Wong, and Jillian Smith-Carpenter
Smith-Carpenter Lab, Fairfield University

The Heme molecular studio presents the unchanged original PEG2 model, mapped component/residue selections, scroll-and-tap chemistry chapters, and expandable source-linked research records. It is independent of the DHFR viewer and the original bundle viewer.

## Scientific scope

The model contains 1,213 atoms and 1,232 explicit bonds. Its Fe–His connections are imposed model bonds. Binding, bundle-specific peroxidase activity and a calibrated sensor response remain experimental questions. The authentic five-second replay uses saved atomic coordinates, without transferred ribbon assignments; physical simulation time is unverified.

## Source and release

The React layout and CSS are in studio-source/src. Molecular rendering is in molecule-engine.js. Scientific data are separate in content.js, application-data.js and figures-data.js. GitHub Pages serves the prebuilt hashed JavaScript/CSS files. The existing asset archives retain the original molecular files, actual figures, VMD replay and NGL license. Public frame provenance removes local filesystem paths. Notebook records are title-only and keep their existing permissions.
